This post serves as a quick reference for setting up all the bug bounty tools I use on Ubuntu 22.04.5 LTS. It’s mainly for future me, so I can reinstall everything smoothly when switching servers.

#### pyenv & go & pipx

```
# === 系统更新与依赖安装 ===
sudo apt update && sudo apt upgrade -y
sudo apt install -y build-essential curl git make zlib1g-dev libssl-dev \
libbz2-dev libreadline-dev libsqlite3-dev libncursesw5-dev libffi-dev \
liblzma-dev xz-utils tk-dev libxml2-dev libxmlsec1-dev

# === 安装 pyenv ===
curl https://pyenv.run | bash
echo -e '\n# pyenv setup' >> ~/.bashrc
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc
echo 'export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo -e 'eval "$(pyenv init --path)"\neval "$(pyenv init -)"' >> ~/.bashrc
source ~/.bashrc

# （可选）安装 Python 版本，例如 3.11.7
pyenv install --list
pyenv install 2.7.18
pyenv install 3.8.18
pyenv install 3.13.1
pyenv install 3.9.18
pyenv global 3.9.18

# === 安装 pipx（需要 pyenv 已安装 Python）===
python -m ensurepip --upgrade
python -m pip install --user pipx
python -m pipx ensurepath
source ~/.bashrc

# === 安装Go ====
wget https://go.dev/dl/go1.21.6.linux-amd64.tar.gz

sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.21.6.linux-amd64.tar.gz

echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
```

- sqlmap&arjun

```
pipx install sqlmap
pipx install arjun
```

#### 子域名

- asnmap

```
go install github.com/projectdiscovery/asnmap/cmd/asnmap@latest
```

- subfinder

```
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest

echo 'export PATH=$PATH:$(go env GOPATH)/bin' >> ~/.bashrc
source ~/.bashrc
```

- amass

```
wget https://github.com/owasp-amass/amass/releases/download/v4.2.0/amass_linux_amd64.zip
unzip amass_linux_amd64.zip
cd amass_Linux_amd64
chmod +x amass
sudo mv amass /usr/local/bin/

mkdir -p ~/.config/amass
cp amass_Linux_amd64/examples/config.yaml ~/.config/amass/
cp amass_Linux_amd64/examples/datasources.yaml ~/.config/amass/
```

- shuffledns

```
go install -v github.com/projectdiscovery/shuffledns/cmd/shuffledns@latest
```

- massdns

```
git clone https://github.com/blechschmidt/massdns.git
```
